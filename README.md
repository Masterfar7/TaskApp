# Task Manager

**Приложение для управления задачами в рамках домашнего задания №2**

Простое Android приложение на Kotlin + Jetpack Compose для ведения списка задач с возможностью добавления названия и описания.

---

## Функционал

### Управление задачами
- **Добавление задачи**: нажатие на кнопку `+` внизу экрана открывает диалог с двумя полями — название (обязательное) и описание (опциональное).
- **Редактирование**: долгое нажатие на задачу вызывает контекстное меню с пунктами «Редактировать» и «Удалить».
- **Удаление**: через контекстное меню.
- **Отметка выполнения**: чекбокс справа от каждой задачи. При отметке:
  - Задача перечёркивается
  - Тускнеет (opacity 40%)
  - Автоматически перемещается в конец списка
  - Анимация перемещения

### Просмотр деталей
- **Клик на задачу** открывает полноэкранный диалог с:
  - Названием задачи
  - Полным текстом описания (с прокруткой, если длинное)
  - Статусом выполнения (✓ Выполнено / ○ Не выполнено)

### Хранение данных
- Использован **Jetpack DataStore** (Preferences) вместо устаревшего SharedPreferences
- Данные сохраняются в формате JSON через **Gson**
- Задачи сохраняются между сеансами работы приложения
- Автоматическая загрузка при запуске через корутины
